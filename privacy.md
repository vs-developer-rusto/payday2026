Политика конфиденциальности
Приложение «Бюджет до зарплаты» (ru.svp.payday2026)

Редакция от 24.10.2026

1. Общие положения

1.1. Настоящая Политика описывает, какие данные обрабатываются при использовании мобильного приложения «Бюджет до зарплаты» (далее — Приложение) для Android.

1.2. Связь по вопросам персональных данных и конфиденциальности: vs_developer@inbox.ru.

1.3. Используя Приложение, вы подтверждаете, что ознакомились с настоящей Политикой. Если вы не согласны с условиями, пожалуйста, не используйте Приложение.

1.4. Приложение рассчитывает ориентировочный дневной бюджет до зарплаты: из суммы на руках вычитаются обязательные платежи, остаток делится на число дней. Расчёт выполняется на устройстве пользователя. У Приложения нет собственной регистрации, аккаунтов и сервера для хранения ваших расчётов. Приложение не подключается к банку, не списывает платежи и не ведёт учёт ваших трат.

2. Какие данные обрабатываются

2.1. Данные, которые вы вводите для расчёта (сумма на руках, число дней до зарплаты, сумма обязательных платежей).
Эти данные используются только для расчёта на вашем устройстве. Оператор не получает их на свой сервер и не хранит их вне вашего устройства.

2.2. История последних расчётов.
История (до 20 записей) сохраняется локально на устройстве, без облака и без аккаунта. Вы можете удалить запись свайпом или через меню записи, а также очистить данные Приложения или удалить Приложение в системе Android.

2.3. Данные для показа рекламы.
В Приложении используется рекламная сеть Яндекс.Реклама: баннер на экране результата и межстраничная реклама при переходе к новому расчёту. Для показа рекламы Приложению нужен доступ в интернет. Рекламный SDK может самостоятельно получать технические данные устройства, необходимые для показа и учёта рекламы (в том числе рекламный идентификатор устройства, IP-адрес и иные технические параметры по правилам SDK). Введённые вами суммы и результаты расчёта в рекламную сеть Приложением не передаются. Обработка данных рекламным SDK регулируется политикой конфиденциальности Яндекса:
https://yandex.ru/legal/confidential/

2.4. Список других приложений.
Раздел «Другие приложения» может один раз за запуск загрузить публичный список приложений линейки (название, идентификатор пакета, ссылки на RuStore и Google Play) с публичного адреса на GitHub Pages: https://vs-developer-rusto.github.io/vacancy2026/links.json. При таком запросе сервер, как и любой сайт, технически видит IP-адрес устройства и стандартные заголовки запроса. Введённые вами данные и результаты расчётов в этот запрос не включаются. Последний полученный список сохраняется на устройстве, чтобы раздел работал без сети.

2.5. Оценка и обновление через магазин.
Приложение может запросить оценку (Review SDK) и проверить наличие обновления (Update SDK) через магазин, из которого оно установлено (RuStore или Google Play). Технические данные при этом обрабатывает соответствующий магазин по своим правилам. Суммы и результаты расчёта туда не передаются.

2.6. Обращения в поддержку.
Если вы пишете на vs_developer@inbox.ru, обрабатываются адрес электронной почты и содержание обращения — только для ответа на ваш запрос.

3. Цели обработки

- выполнение расчёта на устройстве пользователя;
- хранение локальной истории расчётов;
- показ рекламы и учёт её показов (через рекламный SDK);
- актуализация списка других приложений линейки;
- ответ на обращения в поддержку.

4. Передача данных третьим лицам

4.1. Оператор не продаёт персональные данные и не передаёт введённые вами суммы на собственный сервер.

4.2. Третьи стороны, которые могут обрабатывать технические данные в связи с работой Приложения:
- Яндекс (реклама);
- GitHub (публичный список приложений, раздел 2.4);
- RuStore и/или Google Play — при установке, обновлении и запросе оценки через SDK магазина.

4.3. Оператор может раскрыть информацию, если это требуется по закону Российской Федерации или по запросу уполномоченного органа в установленном порядке.

5. Хранение и безопасность

5.1. Данные расчётов и история хранятся на вашем устройстве. Срок хранения определяется вами (удаление записей или данных Приложения).

5.2. Оператор не контролирует безопасность вашего устройства. Рекомендуется использовать актуальные обновления ОС и не передавать устройство посторонним лицам без необходимости.

6. Данные детей

Приложение не предназначено для сбора персональных данных детей. Если вы считаете, что ребёнок передал данные через обращение на email, напишите на vs_developer@inbox.ru — обращение будет удалено.

7. Ваши права

Вы можете:
- не вводить данные, которые не хотите указывать;
- удалить локальную историю в Приложении или через настройки Android («Очистить данные» / удаление Приложения);
- отключить персонализацию рекламы в настройках Android (рекламный идентификатор), если такая опция доступна на устройстве;
- написать на vs_developer@inbox.ru с вопросом об обработке данных.

8. Оговорка о назначении расчёта

Результат расчёта — ориентир для себя. Он не является финансовой, юридической или иной консультацией и не заменяет учёт расходов.

9. Изменение Политики

Оператор может обновлять настоящую Политику. Актуальная редакция публикуется по адресу, указанному в карточке Приложения в магазине. Дата редакции указана в начале документа.
